# 色努式矫形支具数字化设计工作台

浏览器内的青少年脊柱侧弯色努式（Chêneau）矫形支具设计系统：躯干扫描导入 → 自动清理补洞摆正 → 测地笔刷修型 → 等距偏移出壳 → 穿戴评估 → 定稿 STL。全部数据驻留本地 IndexedDB，不上传服务器。

## 技术栈

- **TypeScript + React 18 + Vite**：UI 与状态
- **WebGPU（自写 WGSL compute）**：法线、笔刷位移、等距偏移、Jacobi 热扩散；无适配器时自动回退 CPU
- **WebGL2（自写渲染器，零三方图形库）**：轨道相机、MRT G-Buffer、SSAO、半透明 PETG / 不透明打印料切换
- **IndexedDB**：患者/复诊/扫描/方案/设置元数据 + 网格二进制分表存储

## 运行

```bash
npm install
npm run dev        # 开发，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm run test:geo   # 几何内核单测（Node test，无需浏览器）
```

## 目录结构

```
src/
  geometry/      框架无关的几何内核（可在 Node 单测）
    math.ts        向量/矩阵
    mesh.ts        网格、CSR 邻接表、面积加权法线、Voronoi 面积
    io.ts          OBJ/PLY 解析、二进制 STL 导出
    process.ts     连通域去杂点、半径修剪去手臂、边界环补洞、标记点摆正
    geodesic.ts    测地距离（Dijkstra 主路径 + Heat Method 可选）、CG 求解
    sculpt.ts      测地高斯衰减笔刷、对侧扩张空腔、差值色谱、截面
    shell.ts       法向等距偏移、分区厚度、修剪/后开口、倒圆、水密/薄区/自交校验
    bvh.ts         三角形 BVH 最近点（间隙/穿透/壳厚测量）
    fit.ts         有符号间隙、接触压力、Cobb 矫正预测、打印分段
    generator.ts   参数化测试躯干（侧弯/破洞/杂点/多档面数）
  gpu/           WebGPU 运行时与 WGSL 着色器（GpuCompute.ts + wgsl.ts）
  render/        WebGL2 渲染器（MeshRenderer.ts，SSAO + 半透明）
  db/            IndexedDB 封装与领域 schema
  state/         React Context + reducer
  pages/         六个页面：患者档案/扫描处理/修型/支具壳体/穿戴评估/设置
  components/    3D 视口等复用组件
tests/           几何内核单测
```

## 两条关键精度指标（已由单测钉死）

1. **测地衰减与修型时延**
   - 测地主路径用精确 Dijkstra（二叉堆 O(E log V)），邻接表按网格对象缓存只建一次。
   - 20 万面躯干实测：Dijkstra 约 30ms，一笔修型端到端约 22ms（预算 200ms）。
   - 图距离是真实测地的上界，20 万面边长约 2mm 时相对误差 <1%，对高斯笔刷衰减足够。
   - Heat Method（Crane 2013）管线完整保留，含 CG 求解、零空间投影、钝角权重处理，可在设置页切换；在浏览器常见的钝角三角化扫描网格上默认不启用。

2. **等距偏移壳厚**
   - 内外壁同拓扑，外壁沿面积加权顶点法线外偏 `thickness(v)`，支持 3–5mm 分区。
   - 单测沿法线投影随机抽 300 点，壁厚最大误差 **0.0000mm**（要求 ≤0.1mm）。
   - 注意：工艺壁厚沿法线定义；用全局欧氏最近距离测量会在高曲率处产生虚假偏差，这是测量方法问题而非偏移误差。

## 六个页面与需求对应

| 页面 | 覆盖需求 |
|---|---|
| 患者档案 | Cobb/顶椎/Risser/身高体重录入、复诊 Cobb 折线、方案按复诊归档 |
| 扫描处理 | OBJ/PLY 导入、自动补洞、去手臂/扶架杂点、髂前上棘+腋窝标记点摆正、标记点可拖、内置 5 组合成测试扫描 |
| 修型 | 压垫/释放两类笔刷、测地高斯衰减、毫米深度输入、压垫对侧自动扩张空腔、前后差值双色色谱、逐层截面对比 |
| 支具壳体 | 法向等距偏移、3–5mm 分区厚度、后开口/开窗、切口倒圆、水密检查、<2mm 薄区与自交高亮、超尺寸分段提示、PETG/不透明切换 |
| 穿戴评估 | 套回原始扫描算有符号间隙/穿透、接触压力上色、超阈值点列表可定位、Cobb 矫正预测、STL 与修型单导出、定稿 |
| 设置 | 皮肤耐受阈值、默认壳厚、打印机成型尺寸、倒圆半径、测地算法、数据备份/清空 |

## 已知边界（后续迭代方向）

- 修剪线目前以后开口与高度边界为主，体表自由绘制闭合修剪线的交互已在数据模型预留（`TrimLine`）。
- 矫正预测是压垫深度的力学简化估算（非临床有限元），用于方案对比，不应替代临床判断。
- Playwright 等自动化测试浏览器的 IndexedDB 在导航间可能不保留；普通 Chrome/Edge 持久化正常。
