# 色努式脊柱侧弯矫形支具数字化设计工作台

浏览器内完成躯干扫描处理、修型、壳体设计、穿戴评估到 STL 定稿导出的全流程系统。
TypeScript + 原生 WebGPU（渲染与计算着色器全部自写），病例与模型存 IndexedDB，无后端。

## 运行

```bash
npm install
npm run dev        # 开发服务器（Chrome/Edge 113+，需支持 WebGPU）
npm test           # 39 项单元/端到端测试（Node 端，不依赖 GPU）
npm run build      # 类型检查 + 生产构建
```

## 核心算法与性能

### 测地距离（热法，Crane et al. 2013）
1. 隐式扩散 `(M + tL)u = δ`，余切拉普拉斯 L 与混合面积质量 M
2. 单位化负面梯度 → 面散度
3. 解 Poisson 方程 `Lφ = div`，φ 即测地距离
两个线性系统均由**自写 GPU 共轭梯度求解器**（`cg-solver.ts` + `vectors.wgsl`/`csr.wgsl`）求解，
标量常驻 GPU、单 compute pass 内迭代、零逐轮回读。CPU Dijkstra 图距离作为精度基准（测试对照）。

### 等距偏移壳体
内壁为修型表面，外壁 `p + n·thickness(v)`，边界环桥接为水密实体。
因为厚度直接沿法向精确施加，**随机抽点厚度误差 ≤ 0.1mm**（有测试断言）。

### 性能预算
- 20 万面躯干单笔修型目标 ≤200ms：测地场走 GPU CG，顶点位移走 `deform.wgsl` 计算核，设置页内置自检实测并报告耗时
- 渲染：自写 WebGPU 渲染管线，三点光照 + 顶点邻域 AO + PETG 半透明混合，支持透过壳体观察压垫区

## 目录结构

```
src/core/        纯几何/业务逻辑（可在 Node 测试，不依赖 WebGPU）
  mesh.ts          网格拓扑、邻接、空间哈希、Dijkstra、拉普拉斯
  sculpt*.ts       修型类型/引擎（CPU 回退 + GPU 加速）
  shell.ts         等距偏移、厚度分区、校验、倒圆
  processing.ts    去杂点、补洞、解剖坐标摆正
  synthetic-torso.ts  程序化侧弯躯干（带破洞/噪声/旋转畸形）
  fit-eval.ts      穿戴评估（CPU 参考实现）
  spine-predict.ts Cobb 预测
  repository.ts    IndexedDB 仓储
src/gpu/         WebGPU 设备、CG 求解器、热测地、几何/变形/适配核、渲染器
src/gpu/shaders/ 全部 WGSL 计算/渲染着色器
src/pages/       六个页面
test/            39 项测试：拓扑、IO、补洞、测地基准、CG 数值、壳体厚度、端到端流程、WGSL 绑定一致性
```

## 工程取舍说明

- GPU 不可用时，修型与评估自动回退到 CPU 参考实现，功能不中断（速度下降）
- 程序化躯干生成器保证无真实扫描时也能演示全流程，并提供带真实拓扑的测试夹具
- 接触压力采用弹性基础近似（kPa/mm 线性标定，系数可在设置页调整），属于工程估计而非有限元结果
